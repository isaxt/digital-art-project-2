# Articles shown in the Archive window

Each article = one entry in `../articles.json` + one plain-text file here named by its `file` field.

**To add the full text:** paste it into the `.txt` file, then set `"complete": true` in `articles.json`
(this removes the "full text pending" note).

Text format:
- A blank line separates paragraphs.
- `# Heading` makes a subheading.
- `> text` makes a pull quote / block quote.
- `**bold**` and `*italic*` work inline.
- `---` on its own line draws a divider.

To link the window to the live post, set `"url"` in `articles.json` (the "View original on Substack" link only appears when it is set).

Currently only the passages legible in the screenshots you sent are included. Nothing has been filled in or paraphrased.
